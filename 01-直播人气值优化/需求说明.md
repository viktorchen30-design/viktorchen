### 2. 人气值加成规则（开启后）

:::ok
### 核心规则（简单版）
1. **只有「人气值加成」处于启动中时**，才跑每天的加成脚本。  
2. 每天 **北京时间凌晨 1 点** 跑一次。  
3. 对 **列表全部主播** 生效（不是可选/勾选部分主播）。  
4. 脚本读到每个主播 **当时的人气值**，在此基础上随机增加 **1%～2%**。  
5. 算出的数如果有小数，**向上取整**（只要有小数就进一到整数）。  
6. **手动改人气** 永远以「你最后改完的那个数」为展示基础，不跟历史加成纠缠。
:::

#### 2.1 计算公式

```text
新的人气值 = 向上取整（ 脚本运行时读到的人气值 × (1 + 随机比例) ）

随机比例：1%～2% 之间（含边界以研发实现约定，建议含 1% 与 2%）
向上取整：例如 202.1、202.6 都变成 203
```

#### 2.2 和「手动改人气」的关系（【重要】）

| 场景 | 怎么算 / 怎么显示 |
| --- | --- |
| **脚本跑之前** 改了人气 | 脚本按 **改完后的数** 做 1%～2% 加成 |
| **脚本跑完之后** 又改了人气 | **直接显示你改后的数**，不再把「刚才加成多出来的」再叠上去 |

**例子 1（跑之前改）**  
- 原来人气 100，先改成 **200**  
- 凌晨脚本读到 200，随机涨 **1.3%** → 200 × 1.013 = **202.6** → 向上取整 → **203**

**例子 2（跑之后改）**  
- 人气 100，脚本涨 **1.1%** → 101.1 → 向上取整 → **102**  
- 脚本成功后，运营改成 **200** → 页面显示 **200**  
- 再改成 **100** → 页面显示 **100**  
- （不会在 102 上再自动加一层）

:::key
【注意】加成只看 **脚本跑那一刻读到的人气值**。跑完以后你手改成多少，就展示多少。
:::
