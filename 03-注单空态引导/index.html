需求范围

改造范围

H5／APP 注单页，当前顶部选中场馆A／场馆B，且当前 TAB 无数据时：替换空状态文案并加「立即投注」。点按钮走首页顶栏进馆同一路由。有数据的 TAB 不动。无 BE、无新接口、无埋点。顶部「游戏」维持现网。随 UI 改版一起上线；插图跟当时改版，本期只换标题／说明并加按钮。

成功标准

已推进并上线：无数据时能看见可点的下一步；点了进当前选中馆的原生场馆页，人离开注单页。未点击不自动跳。加载中、失败不当成无数据。

现在空状态没有去向。点「立即投注」＝首页顶栏进馆，不是再点注单页顶部场馆A／场馆B（那只切列表，人还在注单页）。APP 客户端自跳，不复用 H5。未登录进不了注单：登录成功进首页，须再点底栏「注单」。

判定流程

1进页／切 TAB／切馆

以上下文请求当前场馆 + 当前 TAB。

2加载中

既有加载态。切馆先清上一馆空态和按钮。

3失败

既有失败／重试。失败 ≠ 无数据，不出按钮。

4有数据

只出列表，不加引导。

5成功且 0 条

三语文案 +「立即投注」。

6点击

防重复 3～5 秒。走首页顶栏进馆，不是切注单 Tab。

未结算／已结算／预约投注各自按本 TAB 判断。场馆限制不拦这次进馆，下注时再按现网限制。

#规则说明
1展示条件当前场馆 + 当前 TAB 接口成功返回空数组才出文案和按钮；与页上「总计 0 单」对齐
2有数据不出当前 TAB 有任意注单，只出列表
3各 TAB 独立切 TAB 后按新 TAB 自己的结果重新判
4所有进注单入口底栏／投注成功／我的／深链／推送等，只要落在场馆A／场馆B 且该 TAB 无数据，都走本期空状态
5用户主动跳不自动跳场馆；只点「立即投注」后跳
6按当前选中馆选中场馆A → 场馆A原生场馆页；选中场馆B → 场馆B原生场馆页。前端直接判，无后台配置。与「顶部 icon 可配置」无关联
7上下文一致空状态判断、顶部选中项、跳转目标必须同一场馆；旧请求不得覆盖新场馆
8进馆 ≠ 切注单 Tab走首页顶栏进原生场馆的既有路由。禁止做成再点注单页顶部场馆A／场馆B
9APP客户端自行跳转，不复用 H5；目标与该端首页顶栏进馆一致
10打开时默认馆与现网注单页顶部默认选中一致；按钮只认打开后顶部实际选中项
11顶部「游戏」维持现网，不出本期文案与按钮
12不改查询不改注单接口、筛选、状态分类与列表出数。无 BE、无新接口、无埋点
13加载 ≠ 空请求未结束出既有加载态；完整成功返回 0 条才出按钮
14切馆先清旧空态切场馆A／场馆B 后、新数据未回：加载态；不得沿用上一馆空态与按钮
15失败 ≠ 空接口失败沿用既有失败／重试
16其它元素总计、公告、顶底导航维持现状。插图跟 UI 改版；本期只换标题／说明并加按钮
17场馆限制已登录允许进原生场馆；下注时再按既有限制判断
18未登录点底栏「注单」→ 现网登录弹层。登录成功进首页，看不到本期空状态
19页内登录失效踢登录；重新登录进首页，不留在注单、不自动点「立即投注」
20防重复点击后 3～5 秒（以研发既有标准为准），避免连点叠开
21跳转失败复用首页顶栏进馆既有失败处理；不做持续轮询自动再跳
22APP 灰度须发版。旧包维持改造前空状态；新包走本期；旧包不崩

A. 注单数据还没出来

情况怎么处理
接口慢、弱网还在转只出既有加载态；等当前场馆 + 当前 TAB 这一次请求完整结束。不另开轮询、不提前出按钮
接口超时／失败走注单页既有失败／重试。失败 ≠ 无数据，不出空状态按钮
请求成功且 0 条这时才替换文案并出「立即投注」
请求成功且有数据只出列表

B. 已经点了「立即投注」

弱网表现与点首页顶栏进馆一致。

情况怎么处理
跳转过程慢沿用首页顶栏进馆既有等待；按钮进入防重复，避免连点叠页
跳转失败／超时／路由打不开人留在注单页；失败提示与点首页顶栏进馆失败同一套（现网没提示则本期也不新造文案）
用户要再试再点一次按钮（防重复结束后）。不后台自动再跳
技术瞬时重试允许点击当次内部按惯例重试 1～2 次（跟首页顶栏进馆对齐）
定时轮询直到跳成功不做
异常与边界切馆串页、登录、游戏 Tab、灰度。
场景预期
首次进入仍在加载不展示空状态引导
接口超时／失败既有失败或重试，不展示无数据引导
当前 TAB 无数据、其他 TAB 有数据当前 TAB 显示引导；切到有数据 TAB 出列表
快速切换 TAB以后一次有效请求对应的当前场馆 + 当前 TAB 为准
快速切换顶部场馆A／场馆B立刻加载态并清掉上一馆空态／按钮；仅新馆请求完整成功且 0 条后才出对应按钮
旧请求晚到丢弃；不得用 A 的空结果在已选中 B 的页面出按钮
点击时场馆维护沿用首页顶栏进馆既有维护机制
用户受到场馆限制已登录允许进入；下注时再按既有限制提示
未登录点底栏「注单」登录弹层；登录成功进首页；看不到本期空状态
页内登录失效踢登录；重新登录进首页
已登录点「立即投注」直接进对应原生场馆页，不再弹登录。H5 走 H5 进馆；APP 客户端自跳
顶部切到「游戏」现网空状态，无本期按钮
连续点击防重复，只触发一次跳转
APP 灰度旧包维持改造前空状态；新包客户端自行跳转
跳转失败首页顶栏进馆既有失败处理；可有限次即时重试；不轮询自动再跳
验收标准空态、进馆路由、登录、三语。需要时展开。
